# KidsResponds — 六歲的哥哥，兩歲的妹妹

鬧起來的時候翻這一頁：**選誰 → 選狀況 → 照劇本說**；想知道為什麼，再點開「解析」。

線上版：https://jarry6304.github.io/KidsResponds/

## 結構

| 層 | 內容 |
|---|---|
| 1 誰 | 哥哥（6 歲）／妹妹（2 歲），年齡固定在 2027 年 6 月 |
| 2 什麼狀況 | 這個年紀「現在大概是這樣」（身體／腦袋／心理／情緒和說話）＋ 六類狀況的事件磚 |
| 3 劇本 | 先做什麼、可以照說的兩句、接下來孩子可能的反應與你的下一句、別說 |
| 解析（摺疊） | 這件事正常嗎、他可能在要什麼、各學派怎麼看（先看什麼 4 ／ 怎麼說 6） |

## 檔案

單一 `index.html`，零外部依賴，可離線、可列印。事件資料在 `<script>` 內的 `EVENTS` 陣列，一筆一個物件；學派一行文在各事件的 `cores`。

## 來源

學派內容整理自 [parenting-response-mcp](https://github.com/Jarry6304/Parenting-response-mcp) 的 `references/`（tags.md、pingpong.md、tw-parenting-antipatterns.md）。發展狀態為該年齡的一般描述，個別差異正常。教養參考，不是醫療或心理評估。
